# Open Sourcerers of the Git Mountain 🏔️

Eine Plattform für Teamarbeit an Open-Source-Projekten.

- ⏱️ Zeiterfassung (Start/Stop Work)
- 📋 Auftragsverwaltung mit GitHub Links
- 👤 Benutzerprofile
- 🔒 Closed Access (nur Admin erstellt Accounts)
- 🔄 Echtzeit-Synchronisation mit Firebase

**Status:** In Entwicklung

---

## Setup

1. Öffne diese Website
2. Logge dich mit deinem Account ein
3. Starte deine Arbeitszeit
4. Bearbeite Aufträge
5. Sieh deine Statistiken
